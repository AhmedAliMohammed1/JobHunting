# Candidate onboarding

Onboarding collects the minimum useful facts: target roles, locations, workplace/employment preferences, approved skills, and optional work-authorization answers. CV upload accepts only PDF/DOCX up to 8 MB, verifies file signatures, and stores content privately under the authenticated user ID.

Parsing produces reviewable proposals. Users confirm or correct facts before they become application data. Manual edits win over later extraction. Each CV is versioned; applications reference an explicit version so history remains reproducible.
